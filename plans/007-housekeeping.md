## Why this matters

Four small, unrelated cleanups bundled to save overhead:

1. `deleteDashboard` deletes a dashboard's links as N concurrent
   single-document `remove()` calls. The repo's own Known Gotchas section
   (in `docs/TECHNICAL_DESIGN.md`) documents, from hard-won experience, that
   N separate writes each trigger their own reactive emission and that
   writes should be batched: "keep applying local-state updates
   optimistically and as a single batched write". One query-level remove
   fixes the inconsistency.
2. Build-only packages sit in runtime `dependencies`, which misstates the
   app's runtime surface.
3. A user-visible typo ("extention") in the footer.
4. `docs/TECHNICAL_DESIGN.md` misplaces `App.tsx` in its project-structure
   listing.

## Current state

- `src/context/AppStateContext.tsx` — `deleteDashboard` (lines 170–179 at
  planning commit):

  ```ts
  async function deleteDashboard(id: string) {
    if (!db) return
    if (dashboards.length <= 1) return

    const linksToDelete = await db.links.find({ selector: { dashboardId: id } }).exec()
    await Promise.all(linksToDelete.map((l) => l.remove()))

    const doc = await db.dashboards.findOne(id).exec()
    await doc?.remove()
  }
  ```

  The installed rxdb (^17.3.0) exposes both `RxQuery.remove()` (bulk-removes
  all matched docs; `rx-query.d.ts:102`) and `RxCollection.bulkRemove(ids)`
  (`rx-collection.d.ts:111`).

- `package.json` `dependencies` includes build-time-only packages:
  `shadcn` (the CLI — never imported from `src/` as a JS module, but its
  stylesheet IS consumed at build time via `src/index.css:3`:
  `@import "shadcn/tailwind.css";` — so it must be *moved*, never removed),
  `tailwindcss`, `@tailwindcss/vite` (used only in `vite.config.ts`), and
  `tw-animate-css` (consumed via `src/index.css:2`). For a non-published
  Vite app, build-time packages belong in `devDependencies`; Vite bundles
  from `node_modules` regardless of section. Leave `@fontsource-variable/*`
  where they are.

- `src/App.tsx` line 50, inside the footer link text:
