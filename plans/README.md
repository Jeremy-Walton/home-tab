## Findings considered and rejected

(So nobody re-audits these.)

- **RxDB bundle weight**: heavy for a link grid, but it's the documented,
  deliberate architecture choice ("Why RxDB" in `docs/TECHNICAL_DESIGN.md`)
  made for future replication — not debt.
- **`console.warn` monkeypatch in `src/storage/db.ts`**: intentional
  suppression of RxDB's promotional warning; harmless.
- **Base UI behavior deltas** (manual tab activation, `Separator` a11y role,
  `AlertDialogAction` not auto-closing, `AspectRatio` style merge): all
  documented decisions in `docs/TECHNICAL_DESIGN.md`'s Known Gotchas — the
  plans quote the relevant ones where they apply, but none is a defect.
- **Dependency vulnerabilities**: `yarn npm audit --severity high` returned
  no advisories at audit time.
- **Dashboard background CSS injection via `url(...)`**: React sets inline
  styles per-property via CSSOM; a hostile URL can only invalidate the
  value, not escape the property. No fix needed (import-time URL
  normalization in plan 003 tightens it anyway).
- **Drag-cancel (Escape) leaving click suppression armed**
  (`useLinkDragAndDrop.ts`): the pointer release still fires a click that
  clears the ref; could not construct a realistic stuck state. Revisit only
  if a real report appears.
